МАМИНА БАНОЧКА — веб-приложение

Эта папка — веб-версия. Android-проект рядом не изменён.
Голосового ввода нет. Личные записи хранятся в localStorage браузера.
Сеть нужна для первого открытия; service worker сохраняет приложение офлайн.
Никаких внешних библиотек, шрифтов, аналитики и отправки личных записок.

ПУБЛИКАЦИЯ НА GITHUB PAGES
1. Создайте публичный репозиторий mamina-banochka в своём GitHub.
2. Загрузите файлы из этой папки в корень репозитория (не всю Android-папку!).
   Обязательны index.html, style.css, app.js, core.js, sw.js,
   manifest.webmanifest, icon.svg, icon-192.png, icon-512.png и .nojekyll.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Дождитесь ссылки https://ВАШ-АККАУНТ.github.io/mamina-banochka/.
5. Откройте ссылку и дождитесь «Баночка готова к работе без интернета».
Личные резервные копии и подарки НЕ загружайте в репозиторий.
Один адрес сайта используйте постоянно: смена адреса не переносит записи.
При изменении файлов увеличивайте версию CACHE в sw.js.

ЗАПУСК НА КОМПЬЮТЕРЕ
Установленный Node.js: node serve.mjs, затем http://127.0.0.1:48371.
Не открывайте index.html двойным щелчком: модулям и офлайн-режиму нужен HTTP/HTTPS.
Проверка логики: node --test tests.mjs.

ПОДАРОК
Выберите благодарности, подготовьте подарок, отправьте JSON-файл и ссылку.
Получатель открывает ссылку > «Открыть подарок» > выбирает файл > подтверждает.
Файлы содержат открытый текст: отправляйте их только нужному человеку.
Автоматического открытия JSON-файла в приложении не обещаем: нужен выбор файла.
Если отправка файлом браузером не поддерживается, скачайте и прикрепите вручную.

КОПИИ
Сохранить копию: выгружает все записки и прогресс чтения.
Восстановить: добавление без дубликатов либо замена с подтверждением.
Очистка данных сайта, приватный режим и смена устройства могут лишить записок.
Регулярно сохраняйте копию. Приложение не имеет доступа к копии на вашем диске.

ПЕРЕХОД С ANDROID
Записи установленного APK недоступны браузеру. Старое приложение не удаляйте.
Если в нём нет экспорта, перепишите личные записи через «Положить благодарность».
При большом количестве записок потребуется отдельное обновление APK с экспортом.
